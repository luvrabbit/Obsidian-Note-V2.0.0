# Random Integer
## 参数
1. Set size(M):生成的随机数$\in[0, M-1]$
2. Sample time: 生成一个数的时间
3. Samples per frame: 一帧生成多少个数据
Sample time × Samples per frame得到生成一帧数据的时间

这个模块是一帧一帧生成数据的，每一帧数据里有一定数量的数据
真实的数据传输是一位一位传输的，这里相当于提前把数据打包了，对模型仿真的结果不会有影响。

# 16-QAM
## 参数
1. M-ary number:即调制阶数，若M=16，则每个符号携带4比特信息，星座图呈4×4矩形分布
2. input type: - - `Integer`：输入为0到M−1M−1的整数，直接映射到对应星座点。
        
    - `Bit`：输入为二进制向量，每log⁡2(M)log2​(M)位组成一个符号。
        
- **示例**：若M=16M=16，输入为`[0 1 2 ... 15]`（整数模式）或`[0 0 0 0], [0 0 0 1], ...`（二进制模式）。
