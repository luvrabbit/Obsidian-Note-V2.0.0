# Random Integer
## 参数
1. Set size(M):生成的随机数$\in[0, M-1]$
2. Sample time: 生成一个数的时间
3. Samples per frame: 一帧生成多少个数据
Sample time × Samples per frame得到生成一帧数据的时间
