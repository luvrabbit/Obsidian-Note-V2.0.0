# OFDM本质
OFDM时域信号构造的本质，就是发送端信号经过QAM调制为复数信号后，虚部与实部分别被不同频率的子载波相乘（调制），再在时域叠加的结果，而该实现过程，恰好和IFFT、离散余弦变换等公式对应，因此可以用IFFT等时频域变换公式，来实现发送端信号的OFDM频带调制。

OFDM优点：
- 减轻符号间干扰
- 对抗频率选择性衰弱
- 易于与MIMO（多入多出）结合
- 带宽灵活，可利用大带宽
- 更高的频率利用率


# 一些术语
信道的容量：信道可以传输的最大信息速率，记为$C=Blb\left( 1+\frac{S}{N} \right)$
	$B$为信道带宽，$\frac{S}{N}$表示接收信号的信噪比，$lb$表示以二为底数的对数，即$\log_{2}$
	称为香农公式，其成立条件为基于AWGN（加性白高斯噪声信道）
基带信号：需要传输的数据。
载波：承载基带信号，在信道中进行传输。

OFDM符号：基波和各次谐波在基波周期内波形的叠加

# 数据流
生成的随机数按照52个一组进行分类，每个随机数在[0, 15]之间

随后将数据进行交织处理，将突发错误转换为随机错误，有利于前向纠错码的译码，提高了整个通信系统的可靠性。

交织后的数据会经过16QAM编码，每4个bit数据（一个十六进制）编码为一个复数，映射为QAM星座图上的一个点，如果没有信道噪声，那么星座图将为16个点，加上噪声后就会形成围绕16个点的杂乱的点阵。

# N-QAM
## 参数
1. M-ary number:即调制阶数，若M=16，则每个符号携带4比特信息，星座图呈4×4矩形分布
2. input type: 
		Integer：输入为0到M−1的整数，直接映射到对应星座点。
		Bit：输入为二进制向量，每log2​(M)位组成一个符号。
        若M=16，输入为`[0 1 2 ... 15]`（整数模式）或`[0 0 0 0], [0 0 0 1], ...`（二进制模式）。
3. Constellation ordering：星座映射顺序
	    Binary：自然二进制映射（如0→0000, 1→0001, ..., 15→1111）。
        Gray：格雷编码，相邻星座点的二进制编码仅1位不同，降低误码率。
        通常选择Gray编码以减少相邻符号的比特错误。
4. Normalization method（归一化方法）
		作用：调整星座点的幅度，确保信号功率符合要求。
	    选项：
	    Min. distance between symbols：根据最小欧氏距离归一化。
        Average Power：星座点平均功率归一化为1。
        Peak Power：星座点峰值功率归一化为1。
