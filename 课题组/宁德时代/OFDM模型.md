# OFDM本质
OFDM时域信号构造的本质，就是发送端信号经过QAM调制为复数信号后，虚部与实部分别被不同频率的子载波相乘（调制），再在时域叠加的结果，而该实现过程，恰好和IFFT、离散余弦变换等公式对应，因此可以用IFFT等时频域变换公式，来实现发送端信号的OFDM频带调制。

OFDM判决是积分判决！！！

OFDM优点：
- 减轻符号间干扰
- 对抗频率选择性衰弱
- 易于与MIMO（多入多出）结合
- 带宽灵活，可利用大带宽
- 更高的频率利用率


# OFDM参数
采样时间$T_{s}$/采样频率$F_{s}$：一个数据持续时长/数据频率，这个模型中一个数据是[0, 15]，并不是一个bit
OFDM符号：所有**子载波（基波与各次谐波）在同一时间段内（基波周期内）发送的这组并行数据**的集合体（**时域波形叠加**）。
符号长度（符号时长）$T_{sym}$：一个OFDM符号持续的时间，，等于基波周期
符号率：符号长度的倒数=$\frac{1}{T_{sym}}$
子载波间距$\Delta f$：相邻子载波频率差值，等于符号率

# 一些术语
信道的容量：信道可以传输的最大信息速率，记为$C=Blb\left( 1+\frac{S}{N} \right)$
	$B$为信道带宽，$\frac{S}{N}$表示接收信号的信噪比，$lb$表示以二为底数的对数，即$\log_{2}$
	称为香农公式，其成立条件为基于AWGN（加性白高斯噪声信道）
基带信号：需要传输的数据。
载波：承载基带信号，在信道中进行传输。

OFDM符号：基波和各次谐波在基波周期内波形的叠加

载波同步/符号同步：发射和接收处的载波频率相位同步，同时符号积分起始点同步
# 数据流
1. Random Integer生成的随机数按照52个一组进行分类，每个随机数在[0, 15]之间
   ***相当于需要发送的数据流，按照4个bit为一个数进行放置***

2. 随后将数据进行交织处理（打乱数据），将突发错误转换为随机错误，有利于前向纠错码的译码，提高了整个通信系统的可靠性。

3. 交织后的数据会经过16QAM编码，每4个bit数据（一个十六进制）编码为一个复数，映射为QAM星座图上的一个点，如果没有信道噪声，那么星座图将为16个点，加上噪声后就会形成围绕16个点的杂乱的点阵。

4. 此时数据为52×1的复数数据，再在数据的前后分别加入6×1的零数据（补零），视为保护间隔，消除符号间干扰（ISI）

5. 加入导频信息，用于信道估计（此时数据变为64×2）

6. 前32行和后32行交换位置，用于把频谱中心移动到正半轴

7. 64×2的数据经过IFFT（64点）转换为时域信号
	***通过IFFT实现了每个数据经过一个子载波调制，一共64个子载波***
	$x[n] = \frac{1}{N} \sum_{k=0}^{N-1}X[k] \cdot e^{\frac{j 2\pi kn}{N}}$，$n \in 1, 2, 3, \dots N-1$
	其中$N$是IFFT点数，是采样点数量，也是子载波数量，$X[k]$就是QAM调制后的频域数据，$x[n]$就是生成的时域数据
	$e^{\frac{j 2\pi kn}{N}}$中,$k$代表的是第$k$个载波，一共有$N$个子载波，，而$n$代表的是第$k$个载波的第$n$这个采样点，需要说明的是，OFDM不同子载波的持续时间相同，都是一个基波周期，而且对于每一个$k$（每一个子载波）$n$的取值也都是$[0, N-1]$（详见LTE教程4.3）
	而$x[n]/X[k]$中每个点的间隔时间就是采样时间$T_{s}$，所以子载波实际周期为$N*T_{s}=T_{sym}$，

8. 将数据的实部与虚部拆分，实部的128个数据与虚部的128个数据分别通过电池信道模型

9. 再把数据转换为复数数据，经过FFT转换为频域，再经过与前面步骤相反的重组数据，拆分导频数据与原数据。

10. 最后得到52×1的数据，经过QAM解调后得到原始数据

# Random Integer
## 参数
1. Set size(M):生成的随机数$\in[0, M-1]$
2. Sample time: 生成一个数的时间
3. Samples per frame: 一帧生成多少个数据
Sample time × Samples per frame得到生成一帧数据的时间

# N-QAM
## 参数
1. M-ary number:即调制阶数，若M=16，则每个符号携带4比特信息，星座图呈4×4矩形分布
2. input type: 
		Integer：输入为0到M−1的整数，直接映射到对应星座点。
		Bit：输入为二进制向量，每log2​(M)位组成一个符号。
        若M=16，输入为`[0 1 2 ... 15]`（整数模式）或`[0 0 0 0], [0 0 0 1], ...`（二进制模式）。
3. Constellation ordering：星座映射顺序
	    Binary：自然二进制映射（如0→0000, 1→0001, ..., 15→1111）。
        Gray：格雷编码，相邻星座点的二进制编码仅1位不同，降低误码率。
        通常选择Gray编码以减少相邻符号的比特错误。
4. Normalization method（归一化方法）
		作用：调整星座点的幅度，确保信号功率符合要求。
	    选项：
	    Min. distance between symbols：根据最小欧氏距离归一化。
        Average Power：星座点平均功率归一化为1。
        Peak Power：星座点峰值功率归一化为1。
