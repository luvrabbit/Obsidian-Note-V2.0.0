# 定容 并C
**步骤：**

1. **完全放电**：
    
    - 以恒定电流（通常0.5C或1C）放电至截止电压（如2.5V）
        
    - 静置30分钟
        
2. **完全充电**：
    
    - 恒流充电（0.5C）至上限电压（3.65V）
        
    - 转恒压充电至电流降至截止值（如0.05C）
        
3. **静置**：30分钟至1小时
    
4. **标准放电**：
    
    - 以标准倍率（通常0.5C）放电至截止电压
        
    - **记录放电容量**：`容量(Ah) = 放电电流(A) × 放电时间(h)`

现在的问题是调零这个步骤具有很大的问题，因为器材调零的原件丢失，现在代替使用的调零器件在不同角度固定的时候会出现不同的阻抗，

## 问题2
调零没有动过的情况下，仅仅是将电路板取下来再焊上去，得到的电池阻抗也产生了变化
