# 基的定义
向量空间$V$的一组基是其中同时为线性无关组且张成$V$的一个向量组
想象一组基就是最大的线性无关组，如果再加入一个向量，那么就线性相关了
一组基也是最小的张成组，如果删除一个向量，那么就无法张成$V$了
$R^{2}$中的例子就是笛卡尔坐标系单位向量$(0,1),(1,0)$

# 基的充要条件（判定准则）
如果$V$中的每一个向量都是一组向量的线性组合，且组合方式唯一，那么这组向量为$V$的基
$v_{1},\dots v_{m}\in V$且$\forall v\in V,\exists 唯一\{ a_{1},a_{2},\dots a_{m} \}$使得$v = a_{1}v_{1}+\dots a_{m}v_{m}$
那么$v_{1},\dots v_{m}$是$V$的基，反之亦成立

## 证明

# 张成组缩减基，无关组扩充基
每一个不是基的张成组都能通过删除其中某些向量削减为基，
每一个不是基的线性无关组都能通过加入某些不在这个无关组的张成空间中的向量扩充为基
