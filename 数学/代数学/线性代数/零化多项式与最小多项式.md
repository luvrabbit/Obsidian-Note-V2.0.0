# 零化多项式定义
对于一个矩阵$A$，若存在一个多项式$p(\lambda)$使得$p(A)=\mathcal{O}$(零矩阵)，那么称这个多项式为$A$的零化多项式

## 特征多项式为零化多项式
可以证明$|\lambda I-A|$为零化多项式

# 最小多项式
矩阵$A$的最小多项式是首一的次数最小的零化多项式

## 性质
1. 最小多项式的零点和矩阵的特征值相同
2. 最小多项式唯一
3. 最小多项式无重根$\leftrightarrow$矩阵可以对角化
4. 矩阵的初等因子均为$\lambda$的一次多项式$\leftrightarrow$矩阵可以对角
5. 最小多项式就是矩阵的第$n$个不变因子
