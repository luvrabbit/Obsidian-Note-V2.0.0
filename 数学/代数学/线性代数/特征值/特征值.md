# 算子
定义一个将向量空间$V$映射到同一个向量空间的映射$T\in \mathcal{L}(V)$为一个**算子**

# 不变子空间
向量空间$U$为$V$的子空间，对于一个线性映射$T$，如果$\forall v\in U$，$Tv \in U$，就称$U$在$T$是不变的

# 特征值
$T\in \mathcal{L}(V)$,$\lambda \in F$，如果$\exists v \in V,Tv=\lambda v$，就称$\lambda$为$T$的一个特征值，$v$为对应这个特征值的特征向量，**注意这里的$v\neq 0$**

## 特征值的几个等价条件
对于$T\in \mathcal{L}(V),V$是有限维的$\lambda \in F$，则下面几个条件等价:
1. $\lambda$是$T$的特征值
2. $T-\lambda I$不是单射
3. $T-\lambda I$不是满射
4. $T-\lambda I$不可逆

**prove**
如果$\lambda$是$T$的特征值，$\exists v\neq 0,Tv=\lambda v\to (T-\lambda I)v=0$，即$Null(T-\lambda I) \neq \{ 0 \}$，即说明$T-\lambda I$不是单射，同时根据[[可逆性#同一**有限维**空间上的线性映射可逆的充要条件|可逆充要条件]]，可以说明$T-\lambda I$不是满射也不可逆

## 特征向量线性无关
假设$v_{1},v_{2},\dots v_{m}$为$T\in \mathcal{L}(V)$的最小的一组线性相关的特征向量，则$\exists a_{0},a_{1},\dots a_{m}\in F$使得$a_{1}v_{1}+a_{2}v_{2}+\dots+a_{m}v_{m}=0\to (T-\lambda_{m} I)(a_{1}v_{1}+a_{2}v_{2}+\dots+a_{m}v_{m})$ 
$= a_{1}(T-\lambda_{m} I)v_{1}+a_{2}(T-\lambda_{m} I)v_{2}+\dots+a_{m-1}(T-\lambda_{m}I)v_{m}$
$=a_{1}(T-\lambda_{m} I)v_{1}+a_{2}(T-\lambda_{m} I)v_{2}+\dots+a_{m}(T-\lambda_{m}I)v_{m-1}$
$=a_{1}(\lambda_{1}-\lambda_{m})v_{1}+a_{2}(\lambda_{2}-\lambda_{m})v_{2}+\dots+a_{m-1}(\lambda_{m-1}-\lambda_{m})$
