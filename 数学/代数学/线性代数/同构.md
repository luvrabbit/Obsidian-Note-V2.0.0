# 定义
一个同构就是一个[[可逆性#可逆的定义|可逆]]线性映射
对于两个向量空间，如果存在一个将其中一个空间映成（满射）另一个空间上的可逆映射，我们就称这两个向量空间是同构的
**同构就代表着两个空间本质上是相同的**

# 充要条件
两个向量空间是同构的$\leftrightarrow$它们维数相同
**prove**
通过线性映射基本定理与线性映射引理来证明
这里可以注意到，当我们要证明有一个线性映射的时候，经常**用线性映射引理来构造一个映射**

# 定义矩阵算子
$\mathcal{M}$定义为矩阵算子
当它作用于一个线性映射$T\in \mathcal{L}(V,W)$时，即$\mathcal{M}(T)$为一个$n ×m$的矩阵
一般记为$\mathcal{M}(T,v_{1},\dots v_{n},w_{1},\dots w_{m})$（后续简记为$\mathcal{M}(T,V,W)$
当它作用与一个向量$v$时，$\mathcal{M}(v)$即为$v$在一组基下的坐标

# 矩阵的列与线性映射的联系
$\mathcal{M}(Tv_{k},W)=\mathcal{M}(T,V,W)_{.k}$
因为$Tv_{k}=\mathcal{M}(Tv_{k})_{1}w_{1}+\dots+\mathcal{M}(Tv_{k})_{m}w_{m}$
$Tv_{k}=\mathcal{M}(T,V,W)_{1k}w_{1}+\dots+M(T,V,W)_{mk}w_{m}$
比较得到结果

# 线性映射与矩阵乘法的联系
$\mathcal{M}(Tv,W)=\mathcal{M}(T,V,W)\mathcal{M}(v,V)$
即线性变换作用于一个向量后的坐标=这个线性变换的矩阵乘以这个向量的坐标
由上个标题结论易得

# 线性映射之积的矩阵
$\mathcal{M}(ST,U,W)=\mathcal{M}(S,V,W)\mathcal{M}(T,U,V)$
于是可以得到
$I=\mathcal{M}(I,V_{1},V_{1})=\mathcal{M}(I,V_{2},V_{1})\mathcal{M}(I,V_{1},V_{2})$
$I=\mathcal{M}(I,V_{2},V_{2})=\mathcal{M}(I,V_{1},V_{2})\mathcal{M}(I,V_{2},V_{1})$
