# 单射
一个函数$T，V\to W$，若$Tu=Tv$蕴涵$u=v$则称$T$为单射（一对一,one to one）
形象理解就是同一个数会映射为同一个数

## 单射充要条件
$T \in \mathcal{L}(V,W)$为单射当且仅当$\text{null}T=\{ 0 \}$

若$T$为单射，由于$T (0)=0$，所以可得$\text{null}T=\{ 0 \}$

若$\text{null}T=\{ 0 \}$，设$Tu=Tv$，则$T(u-v)=0$由于$T$的零空间为$\{ 0 \}$
所以可得$u-v=0$，即$u=v$

# 满射
一个函数$T,V\to W$的值域为$W$则称$T$为满射，也成为映成(onto)
一个线性映射是否为满射，取决于我们 认为它映射到哪个向量空间

# 线性映射基本定理
$V$为有限维且$V \in \mathcal{L}(V,W)$
