# 作业
使用取对数的方法来线性化非线性最小二乘问题是一种常见的技术。对于给定的模型 \( y = a e^{bcos(x)} \)，我们可以通过对等式两边取自然对数来将其转换为线性形式。这样，我们得到：

\[ ln(y) = ln(a) + b cos(x) \]

现在，我们可以将这个等式看作是关于 \( \ln(y) \) 和 \( \cos(x) \) 的线性回归问题。这里，\( \ln(a) \) 是截距，\( b \) 是斜率。我们可以使用线性最小二乘法来估计 \( \ln(a) \) 和 \( b \)。

以下是使用MATLAB实现的代码：

```matlab
function [a, b] = curfit(x, y)
    if any(y <= 0)
        error('All elements of y must be positive.');
    end

    A = [ones(length(x), 1) cos(x')];
    
    % 计算ln(y)
    ln_y = log(y');
    
    % 求解参数
	Z = A \ ln_y
    
    % 提取参数
    ln_a = Z(1);
    b = Z(2);
    
    % 转换回原始参数
    a = exp(ln_a);
    
    % 画出拟合函数曲线
    x_fit = linspace(min(x), max(x), 100);
    y_fit = a * exp(b * cos(x_fit));
    plot(x, y, 'o', x_fit, y_fit, '-');
    title('Data and Fitted Function');
    xlabel('x');
    ylabel('y');
    legend('Data', 'Fitted function');
end
```

这段代码首先检查输入向量 `x` 和 `y` 的长度是否一致，并且 `y` 中的所有元素都必须是正数，因为对数函数只对正数定义。然后，它构建了一个设计矩阵 `A`，其中包含了截距项（全为1的列）和 `cos(x)` 项。接着，它计算了 `y` 的自然对数 `ln_y`，并使用正规方程求解线性方程组来估计参数 `ln_a` 和 `b`。最后，它将 `ln_a` 转换回原始参数 `a`，并绘制了数据点和拟合函数的曲线。
