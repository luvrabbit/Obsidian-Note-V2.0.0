# 系统时钟

referenced: [Clock Configuration in STM32. An in-depth guide to using the STM32… | by Rohit Nimkar | Medium](https://medium.com/@csrohit/clock-configuration-in-stm32-6a058da220e0)
## HSI
HSI是由内部晶振产生的时钟信号，16MHz但是由于其一般不准确，我们不使用

## HSE
这个是主要使用的时钟源，来自于外部用户提供的时钟信号，它可以是：
1. 外部直接提供时钟信号，这种适用于有一个稳定时钟源的情况，这里不介绍
2. 外部提供晶振产生时钟信号，这个是普遍使用的（因为我们的板子上总得有一个时钟源）

- **==PCB设计注意！！==**
**The resonator and the load capacitors have to be placed as close as possible to the oscillator pins in order to minimize output distortion and startup stabilization time. The loading capacitance values must be adjusted according to the selected oscillator.**
