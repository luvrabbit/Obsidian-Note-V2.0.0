# 拉普拉斯法
$\phi(t) = e^{At} = \mathcal{L}^{-1}\{[sI-A]^{-1}\}$

# 凯莱哈密尔顿
1. 求特征值
2. 设$e^{At} = a_{0}I+a_{1}A+a_{2}A^{2}$A是几阶的就设几个a
3. 把特征值带入$A$，得到三个方程，解出a
4. 带入$e^{At} = a_{0}I+a_{1}A+a_{2}A^{2}$得到结果

# 求$x(t_{1})$
$x(t_{1}) = e^{At}x(0)$

# 已知$e^{At}$求$A$
$\frac{d}{dt}e^{At} = Ae^{At}$
令$t=0$
得$A=\frac{d}{dt}e^{At}|_{t=0}$
