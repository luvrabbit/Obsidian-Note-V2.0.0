# 方法与思路
1. **图像读取**：使用`imread`函数读取图像文件。
2. **图像转换**：将`Mat`类型的图像转换为`vector<float>`类型的一维数组。
3. **卷积操作**：对图像进行卷积操作，卷积核选取拉普拉斯算子，并记录时间。
4. **图像增强**：将卷积结果加回到原始图像数据上，实现增强效果。
5. **结果转换**：将增强后的一维数组转换回`Mat`类型的图像。
6. **显示结果**：使用`imshow`函数显示增强前后的图像，并显示消耗时间。

## 主要模块（函数）
`MatToVector`：将opencv读取的`Mat`类型的图像转换为`vector<float>类型
`convolution`：将转换后的图像与卷积核进行卷积
`convolutionSIMD`：将转换后的图像与卷积核进行卷积，但使用SIMD进行加速

# 代码分析
`convolution`函数中：
```cpp
vector<float> convolution(const vector<float>& imagevec, const vector<vector<float>>& kernel,
    int width, int height,int padding=1, int stride=1)

// 省略变量定义初始化

for (int y = 0; y < resultHeight; ++y) {
    for (int x = 0; x < resultWidth; ++x) {
        for (int i = 0; i < kernelHeight; ++i) {
            for (int j = 0; j < kernelWidth; ++j) {
                int ny = y * stride + i - padding;
                int nx = x * stride + j - padding;
                if (ny >= 0 && ny < height && nx >= 0 && nx < width) {
                    int idx = (ny * width + nx) * 3;
                    for (int c = 0; c < 3; ++c) {
                        result[(y * resultWidth + x) * 3 + c] += imagevec[idx + c] * kernel[i][j];
                    }
                }
            }
        }
    }
}
```
使用四层嵌套循环遍历图像和卷积核，计算加权和得到卷积后的结果，同时也能够通过将二维矩阵压缩到一维，实现任意矩阵的卷积操作。

`convolutionSIMD`函数中：
```cpp
    for (int y = 0; y < resultHeight; ++y) {
        for (int x = 0; x < resultWidth; ++x) {
            __m128 resultValues[3] = { _mm_setzero_ps(), _mm_setzero_ps(), _mm_setzero_ps() };
            for (int i = 0; i < kernelHeight; ++i) {
                for (int j = 0; j < kernelWidth; ++j) {
                    int ny = y * stride + i - padding;
                    int nx = x * stride + j - padding;
                    if (ny >= 0 && ny < height && nx >= 0 && nx < width) {
                        int idx = (ny * width + nx) * 3;
                        __m128 imageValues[3] = { _mm_loadu_ps(&imagevec[idx]), _mm_loadu_ps(&imagevec[idx + 1]), _mm_loadu_ps(&imagevec[idx + 2]) };
                        __m128 kernelValue = _mm_set1_ps(kernel[i][j]);
                        for (int c = 0; c < 3; ++c) {
                            resultValues[c] = _mm_add_ps(resultValues[c], _mm_mul_ps(imageValues[c], kernelValue));
                        }
                    }
                }
            }
            int resultIndex = (y * resultWidth + x) * 3;
            result[resultIndex] = static_cast<float>(_mm_cvtss_f32(_mm_hadd_ps(_mm_hadd_ps(resultValues[0], resultValues[0]), resultValues[0])));
            result[resultIndex + 1] = static_cast<float>(_mm_cvtss_f32(_mm_hadd_ps(_mm_hadd_ps(resultValues[1], resultValues[1]), resultValues[1])));
            result[resultIndex + 2] = static_cast<float>(_mm_cvtss_f32(_mm_hadd_ps(_mm_hadd_ps(resultValues[2], resultValues[2]), resultValues[2])));
        }
    }
```
使用`__m128`类型（SIMD指令集的数据类型）来存储和操作四个浮点数，从而一次性处理四个数据，加速计算。

## 分析加速比不到2.0的原因
1. 使用了三个`__m128`寄存器来累加结果。如果寄存器压力过大，可能会导致寄存器溢出到栈上，增加内存访问负担。
2. 数据的加载、乘法和加法操作之间可能存在数据依赖，限制了并行执行的指令数量。
3. 合并结果向量时，使用了`_mm_hadd_ps`和`_mm_cvtss_f32`，可能因为多次数据移动影响性能。
4. 数据量较小，可能导致加速比不会有显著变化。
