# 方法与思路
1. **图像读取**：使用`imread`函数读取图像文件。
2. **图像转换**：将`Mat`类型的图像转换为`vector<float>`类型的一维数组。
3. **卷积操作**：对图像进行卷积操作，卷积核选取拉普拉斯算子，并记录时间。
4. **图像增强**：将卷积结果加回到原始图像数据上，实现增强效果。
5. **结果转换**：将增强后的一维数组转换回`Mat`类型的图像。
6. **显示结果**：使用`imshow`函数显示增强前后的图像，并显示消耗时间。

## 主要模块（函数）
`MatToVector`：将opencv读取的`Mat`类型的图像转换为`vector<float>类型
`convolution`：将转换后的图像与卷积核进行卷积
`convolutionSIMD`：将转换后的图像与卷积核进行卷积，但使用SIMD进行加速
