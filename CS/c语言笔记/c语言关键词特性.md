# 总结
|用法|作用域|生命周期|初始化时机|与普通变量/函数的区别|
|---|---|---|---|---|
|修饰局部变量|仅限于定义它的函数内部|整个程序运行期间|程序启动时（首次调用函数时）|普通局部变量在每次函数调用时重新初始化|
|修饰全局变量|仅限于定义它的文件|整个程序运行期间|程序启动时|普通全局变量可被其他文件通过extern访问|
|修饰函数|仅限于定义它的文件|整个程序运行期间|程序启动时|普通函数可被其他文件调用|

# 修饰函数（静态函数）

**特点：**
- 作用域仅限于定义它的文件，不能被其他文件通过函数名调用
- 与普通函数不同，普通函数默认具有外部链接性，可以在其他文件中调用
```
#include <stdio.h> 
static void private_func() { 
	printf("This is a private function.\n"); 
} 

void public_func() {
	private_func(); // 在同一个文件内可以调用 
}
```
