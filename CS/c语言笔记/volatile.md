| 特性    | C/C++       | Java                        |
| ----- | ----------- | --------------------------- |
| 主要目的  | 防止编译器优化     | 保证可见性 + 禁止指令重排              |
| 原子性   | ❌ 不保证       | ❌ 不保证（`i++` 仍非原子）           |
| 内存屏障  | ❌ 不插入（需手动加） | ✅ 插入内存屏障（StoreLoad barrier） |
| 多线程安全 | ❌ 不能用于同步    | ✅ 可用于简单同步（如单例 double-check） |
