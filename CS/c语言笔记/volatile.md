| 特性    | C/C++       | Java                        |
| ----- | ----------- | --------------------------- |
| 主要目的  | 防止编译器优化     | 保证可见性 + 禁止指令重排              |
| 原子性   | ❌ 不保证       | ❌ 不保证（`i++` 仍非原子）           |
| 内存屏障  | ❌ 不插入（需手动加） | ✅ 插入内存屏障（StoreLoad barrier） |
| 多线程安全 | ❌ 不能用于同步    | ✅ 可用于简单同步（如单例 double-check） |

### ✅ 应该用：

- 访问**内存映射硬件寄存器**
- **中断**与主程序共享的变量
- **信号处理函数**中修改的全局变量
- **嵌入式延时循环**（防止被优化掉）
- **很多时候用于内联汇编**

### ❌ 不应该用：

- 多线程共享的计数器、队列等（用 `atomic` 或 `mutex`）
- 试图用它实现锁或同步原语
- 替代 `const` 或 `atomic`
