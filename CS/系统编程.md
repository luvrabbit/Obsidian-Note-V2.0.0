## 模板类使用时的链接问题
如果在编写模板类代码的时候使用声明与定义分离的方式，例如：
```cpp
// MyMatrix.hpp

#ifndef MYMATRIX_HPP
#define MYMATRIX_HPP

...

template<typename T>
class MyMatrix {
private:
	std::vector<std::vector<T>> data;
	size_t r;
	size_t c;
public:
	...
	...
	MyMatrix<T> operator*(const T multi) const;
	...
	...
}
```

```cpp
// MyMatrix.cpp
#include "MyMatrix.hpp"
...
template<typename T>
MyMatrix<T> operator*(const T multi) const {
	MyMatrix<T> result(r, c);
	for (size_t i = 0; i < r; i++) {
		for (size_t j = 0; j < c; j++) {
			result.data[i][j] = multi * data[i][j];
		}
	}
	return result;
}
```
像这样声明与实际定义分离的情况，在模板实例化的时候会出现链接错误（LINK2019）
```cpp
// main.cpp
#include "MyMatrix.hpp"
int main() {
	MyMatrix<double> temp(buffer, 100, 200);
    MyMatrix<double> temp2(buffer, 200, 100);
    MyMatrix<double> result = temp * temp2;
}
```
在实际编译过程中，上述代码会出现链接错误，原因如下：
编译的时候调用了一个double类型的乘法重载函数，所以编译器会到hpp文件中找此函数，hpp文件中能找到，但是hpp文件中没有定义，于是在链接过程中编译器就会尝试将cpp文件中的函数定义链接过去，但是cpp文件中没有double类型的实例，于是产生链接错误。

	解决办法
	将模板类中函数定义放入hpp文件中，从而在编译的时候就能将完整的函数实例化
# const相关
## 拷贝构造函数的参数加const
一个类的拷贝构造函数的参数一定需要是const 修饰的，原因为：
1. **避免修改原始对象**： 拷贝构造函数的目的是创建一个新对象，该对象是另一个对象的副本。使用`const`参数可以确保在拷贝构造过程中原始对象不会被修改。这是一个重要的安全保障，因为它允许用户放心地传递对象，而不必担心对象在拷贝过程中被改变。
    
2. **提高函数的通用性**： 如果拷贝构造函数的参数不是`const`，那么它只能接受非常量对象作为参数。使用`const`参数允许拷贝构造函数接受常量对象和非常量对象，这增加了函数的灵活性和通用性。
    
3. **避免不必要的拷贝**： 如果参数不是`const`，那么在传递非常量对象时，编译器可能会生成一个临时对象（如果使用了`const`对象，则不能生成这样的临时对象，因为`const`对象不能绑定到非`const`的非常量引用上）。这可能会导致不必要的额外拷贝和性能损失。通过使用`const`参数，可以避免这种情况，因为可以直接传递对象的引用，而不需要生成临时对象。
    
4. **与C++标准库的一致性**： C++标准库中的容器和迭代器等都遵循使用`const`参数的约定。为了与标准库保持一致，自定义类型的拷贝构造函数也应该使用`const`参数。
    
5. **避免悬挂引用**： 如果一个对象被销毁了，但是它的引用仍然被使用，那么这个引用就被称为悬挂引用。使用`const`参数可以避免拷贝构造函数意外地创建悬挂引用，因为如果原始对象被销毁，编译器会阻止对`const`对象的任何修改，从而避免了悬挂引用的问题。
    
6. **提高代码的可读性和意图表达**： 使用`const`参数可以清晰地表明拷贝构造函数不会修改传入的对象，这提高了代码的可读性和意图表达。
```cpp
class MyClass {
private:
//成员定义
public:
	MyClass (const MyClass c1) {
	// c1成员全部拷到this中
}
}
```

## 函数定义括号后加const
代表这个函数不会修改类的成员变量
```cpp
class aa{
	int num;
public:
	aa(){
		int b =10;
		num = b;
	};
	void out1(){
		cout<<num<<endl;
	}
	void out2() const{
		cout<<num<<endl;
	}
	void out3() const{
		num+=10; //Error, const function cannot modify its data members
		cout<<num<<endl;
	}
};
```
# 引用相关
## 返回值加&代表按引用返回
```cpp
const std::vector<int>& getVector() {
    static std::vector<int> vec = {1, 2, 3};
    return vec;
}
```
上面这段代码最后返回的是vec的引用，而不是拷贝一个vec返回，再销毁原来的vec

## 函数参数加&引用
1. 如果不加引用，在函数调用的时候必须得复制一份形参，然后如果这个形参是一个数组，或者是一个类，里面东西很多，那么复制一份就非常耗费资源
2. 引用的参数可以在函数内修改，从而传递到函数外面
